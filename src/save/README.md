# Orca Adventure — Agent 8 Save/Load Module

Portable, versioned JSON save/load service for browser games.

- Source: `src/save/`
- API and schema: `docs/SAVE_API.md`
- Tests: `tests/save.test.mjs`
- Isolated browser harness: `test-scene/index.html`

Run tests with `npm test`. No third-party dependencies are required.
